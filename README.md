# Groceri-site

The public pages for [Groceri](https://github.com/luojiahai/Groceri), served by GitHub Pages.

Groceri's own repository is private, so the pages that have to be readable by anyone — today,
the privacy policy the App Store listing and the app's pre-camera explainer both link to — live
here instead, where changing what the app promises still reviews like any other pull request.

| page | URL |
| --- | --- |
| Privacy policy | <https://luojiahai.github.io/Groceri-site/privacy> |

Plain HTML, no build step. `.nojekyll` keeps GitHub Pages serving the files as they are.
